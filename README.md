# 津派砖雕全流程工艺模拟系统

天津非物质文化遗产数字工坊交互项目。系统以一张完整的津派博古花鸟砖雕线稿为工艺依据，按传统七道工序完成选料、磨面、落样、粗雕、细雕、精修和成品展示。

## 运行方式

直接双击 `index.html` 即可运行。项目不需要后端、不需要安装依赖，也不依赖网络资源。

建议使用最新版 Chrome、Edge 或 Chromium 浏览器，以桌面分辨率 1440 x 900 或更高进行答辩演示。

手机端请横屏打开。系统会自动切换为紧凑操作布局，并支持长按保存成品图片或调用手机系统分享面板。

## 七道工序

1. 选料：在优品青砖与微瑕疵青砖之间选择，不同砖质对应不同细雕深度容错。
2. 打磨砖面：按住鼠标拖动磨石覆盖整块砖面，平整度达到 85% 后解锁下一步。
3. 起稿落样：拖动线稿平移，滚轮缩放，确认后同步锁定后台区域蒙版与深度图。
4. 粗雕去地：粗刻刀只可作用于背景地子；碰触主体或边框时自动收刀并震动提示。
5. 细雕修纹：细刻刀只可作用于纹样主体，并根据深度图生成不同浮雕层次；同一局部过度深挖会产生裂纹。
6. 修边抛光与清灰：依次使用修边刀、磨石、毛刷，完成三类精加工。
7. 成品展示：支持自由旋转、白台/四合院影壁场景切换、高清截图、文物同款对照与工艺介绍。

## 操作说明

- 选料和成品阶段：按住鼠标拖动可旋转砖体。
- 落样阶段：按住鼠标拖动平移底稿，滚轮缩放。
- 雕刻阶段：按住鼠标左键沿允许区域走刀。
- 顶部进度条显示当前工序完成度，工艺不达标时无法进入下一步。
- 每一步右下角都可点击“一键完成本步骤”，系统会按标准工艺自动完成当前区域，不会越区雕刻。
- 数字键 `1` 至 `5` 可快速切换已解锁工具，`R` 重置当前工序，`Enter` 完成当前工序。

## 核心工艺约束

### 三层底图同步

`pattern-library.js` 使用同一组矢量路径分别绘制三层数据：

- 线稿层：用户可见的黑色传统工艺底稿。
- 区域蒙版层：背景值为低灰度，主体为高灰度，边框使用独立灰度。
- 深度灰度层：亮值表示浅雕，暗值表示深雕。

因此线稿、区域判定和浮雕深度在平移、缩放后仍保持严格对齐。

### 区域下刀判定

- 粗刻刀仅采样背景蒙版。
- 细刻刀仅采样纹样主体蒙版。
- 修边刀仅在主体或边框的边界邻域生效。
- 磨石与毛刷按照各自工序覆盖目标区域。

每次落刀都会先完成区域分类，再执行视觉变化。错区操作只触发反馈，不会修改雕刻层。

### 深度上限与崩裂

细雕阶段会读取深度灰度值作为目标浮雕高度。系统在网格坐标中累计同一位置的走刀次数，超过砖质容错上限后记录裂纹和崩边，并停止继续加深。

### 工序锁

`app.js` 中的 `canAdvance()` 统一控制每一步的解锁条件。无论通过按钮、键盘还是重复点击，都无法跳过未达标的工序。

## 论文可引用的技术说明

项目采用纯前端 Canvas 2D 渲染方案。砖体材质通过像素噪声、宽度变化、细孔与色调梯度实时生成；线稿、蒙版和深度数据由程序化矢量路径构建；浮雕观感由区域深度、走刀覆盖、明暗叠色、裂纹与抛光高光共同形成。

系统没有把制作过程做成自动播放动画，而是把每一步的关键结果交给用户操作。约束层负责判定操作是否有效，渲染层负责把有效操作即时转化为砖面质感变化，状态层负责维护七步工艺流程和答辩演示所需的进度可视化。

## 修改入口

- 修改七步标题、说明和知识点：`js/app.js` 顶部的 `STEPS`。
- 修改工具名称、图标和快捷键：`js/app.js` 顶部的 `TOOL_DEFINITIONS`。
- 修改线稿构图：`js/pattern-library.js` 中的 `createShapeSet()`。
- 修改青砖颜色、孔隙和初始裂纹：`js/brick-renderer.js` 中的 `buildTextures()`。
- 修改各工序达标值：`js/app.js` 中的 `canAdvance()`。
- 修改截图构图与导出尺寸：`js/brick-renderer.js` 中的 `exportComposite()`。

## 答辩演示建议

建议按顺序演示一次完整流程，并在粗雕阶段故意触碰纹样区域，展示自动收刀与纠错提示；在细雕阶段对同一位置连续下刀，展示深度上限与裂纹反馈。成品页可切换四合院影壁场景并保存截图，再打开“文物同款对照”说明造型体系。
